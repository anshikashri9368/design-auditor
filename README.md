# 🎨 AI Design Auditor

An **AI-powered UI/UX Design Auditing Platform** that analyzes digital interfaces and provides intelligent feedback on **usability, accessibility, visual consistency, design-system compliance, responsiveness, and user experience**.

AI Design Auditor helps designers and developers identify potential design problems before development by automatically analyzing interface designs and generating **actionable recommendations with severity levels and improvement suggestions**.

---

# 🚀 Why AI Design Auditor?

A visually attractive interface does not necessarily provide a good user experience.

A design may contain:

* Poor contrast
* Inconsistent spacing
* Weak visual hierarchy
* Unclear buttons
* Accessibility issues
* Inconsistent typography
* Poor alignment
* Missing interaction states
* Overcrowded layouts
* Inconsistent design-system usage

Finding these problems manually can be time-consuming.

**AI Design Auditor automates the first level of design review and provides structured feedback to designers.**

# 🚀 Installation

## 1. Clone Repository

```bash
git clone https://github.com/yourusername/ai-design-auditor.git
```

## 2. Navigate to Project

```bash
cd ai-design-auditor
```

## 3. Create Virtual Environment

```bash
python -m venv venv
```

### Windows

```bash
venv\Scripts\activate
```

### Linux / macOS

```bash
source venv/bin/activate
```

## 4. Install Dependencies

```bash
pip install -r requirements.txt
```

## 5. Configure Environment Variables

Create a `.env` file:

```env
SECRET_KEY=your_secret_key
DEBUG=True

DB_NAME=ai_design_auditor
DB_USER=root
DB_PASSWORD=your_password
DB_HOST=localhost
DB_PORT=3306

AI_API_KEY=your_api_key
```

## 6. Run Migrations

```bash
python manage.py makemigrations
python manage.py migrate
```

## 7. Start Server

```bash
python manage.py runserver
```

Open:

```text
http://127.0.0.1:8000/
```
